# Engagement System ➕
Actions are hour-long states that can be interrupted. Resolution happens at hour-end.

## Time Flow
- on_hour(N): Scheduled actions trigger, entities initiate engagements
- [10-sec ticks]: Movement continues, encounter checks can INTERRUPT engagements
- on_hour_end(N): Uninterrupted engagements RESOLVE (damage dealt, blessings stolen, etc.)
- on_hour(N+1): Next scheduled actions begin

## Engagement Properties
- engagement_type: COMBAT, ROBBERY, TENDING, TRADING, FEEDING, PROTECTING, PILLAGING
- initiator: The entity that started the engagement
- target: Entity or location being engaged with
- started_hour: When the engagement began
- interruptible: Whether encounters can break it (most are, some like FEEDING may not be)

## Engagement States (for Mobile entities)
- engaged_with: Optional[Engagement] - current engagement if any
- engage(target, type) - start engagement, both parties aware
- disengage(reason) - break engagement, try to resume previous action or flee

## Interrupt Behavior
When an engagement is interrupted:
1. Both parties disengage
2. Initiator tries to continue original scheduled action if still valid
3. If original target dead/gone, action becomes INTERRUPTED state
4. Some interrupts cause flee behavior (dragon scares bandit)

## Resolution Behavior (on_hour_end)
If still engaged when hour ends:
- ROBBERY: Blessing transferred, bandit retreats
- COMBAT: Outcome based on combatants (hero mood unknown to bandit until now)
- TENDING: Spirit receives blessing
- TRADING: Gossip exchanged, caravan returns
- FEEDING: Target consumed
- PROTECTING: Protector remains in place
- PILLAGING: Blessings taken from ruins/treasury

## Entity-Specific Engagement Rules

### Bandit
- Initiates ROBBERY on caravans (doesn't check for heroes first)
- Initiates COMBAT on heroes (doesn't know their mood until resolution)
- INTERRUPTED by: dragon proximity (flees), hero intervention
- On interrupt: flees to nearest forest

### Hero  
- Can INTERRUPT nearby robberies/attacks by initiating COMBAT
- Vengeful: kills bandits at resolution
- Tired: loses to dragons at resolution (unless in settlement)
- Adventurous/Mercenary: actively patrols for engagements to interrupt

### Dragon
- Proximity alone can INTERRUPT bandit engagements (fear)
- Good dragons INTERRUPT attacks on humans by engaging attacker
- Territorial dragons initiate COMBAT when near domain
- CIRCLE action is a pre-engagement phase (not interruptible?)

### Caravan
- Passive - can be engaged by others, cannot initiate
- When ROBBERY interrupted, continues original route
- When target settlement dies mid-journey, flees to nearest

### Settlement
- Passive - can be engaged by attackers
- Heroes within 3 tiles can INTERRUPT attacks by engaging attacker
